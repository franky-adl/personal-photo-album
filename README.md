# Personal Photo Album

![Personal Photo Album](cover.webp)

A 3D interactive photo album built with [React Three Fiber](https://r3f.docs.pmnd.rs/) and [Three.js](https://threejs.org/), using license free assets. Sit at a virtual desk, open the album, and flip through your personal travel photos and videos — something a paper album can’t do!

## Installation

Requires [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/).

```bash
pnpm install
pnpm run dev
```

Then open the local URL printed in the terminal (Vite usually serves at `http://localhost:5173`).

To create a production build:

```bash
pnpm run build
```

Output goes to `dist/`.
